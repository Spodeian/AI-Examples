# Combinatorial Routing and Constraint Satisfaction Neural Solvers

## 1. Combinatorial Optimization and the NP-Hard Landscape

Combinatorial Optimization Problems (COPs)—such as the Traveling Salesperson Problem (TSP), Capacitated Vehicle Routing Problem (CVRP), Boolean Satisfiability (SAT), and Maximum Cut (Max-Cut)—exhibit superexponential search spaces $\mathcal{O}(N!)$ or $\mathcal{O}(2^N)$. While exact solvers (e.g., Concorde, Gurobi) guarantee optimality via branch-and-bound and cutting planes, their worst-case exponential time complexity makes real-time industrial dispatching intractable. Neural combinatorial optimization learns data-driven heuristics to output near-optimal solutions in milliseconds.

## 2. Vehicle Routing and TSP Formulation

In the 2D Euclidean Traveling Salesperson Problem, a solver seeks a minimal-length Hamiltonian cycle visiting each node in $V = \{x_1, \dots, x_N\} \subset \mathbb{R}^2$ exactly once:

$$\min_{\pi \in \Pi_N} \text{Cost}(\pi) = \sum_{i=1}^{N-1} \| x_{\pi_i} - x_{\pi_{i+1}} \|_2 + \| x_{\pi_N} - x_{\pi_1} \|_2$$

where $\Pi_N$ is the set of all permutations of $\{1, \dots, N\}$. Evaluating candidate tours and evaluating delta-costs during local search (2-opt, 3-opt) constitutes the fundamental inner loop of routing heuristics.

## 3. Pointer Networks: Autoregressive Pointing with Attention

Standard sequence-to-sequence models rely on a fixed output dictionary. Vinyals et al. introduced Pointer Networks, which dynamically point to elements within the variable-length input sequence using attention:
- At decoding step $t$, the decoder hidden state $d_t \in \mathbb{R}^D$ attends to all node embeddings $\{e_1, \dots, e_N\}$:
  $$u_{t, i} = v^T \tanh(W_1 e_i + W_2 d_t)$$
- **Visited Masking:** To enforce valid permutations without repeated node visits, already visited nodes $\mathcal{V}_t = \{\pi_1, \dots, \pi_{t-1}\}$ are masked out with large negative values:
  $$u'_{t, i} = \begin{cases} u_{t, i} & \text{if } i \notin \mathcal{V}_t \\ -\infty & \text{if } i \in \mathcal{V}_t \end{cases}$$
- The next visited city is sampled or greedily selected from:
  $$P(\pi_t = i \mid \pi_{<t}, X) = \operatorname{softmax}(u'_t)_i$$

## 4. Graph Neural Networks for Edge Sparsification and Heatmaps

Rather than decoding tours node-by-node, non-autoregressive GNNs process the complete graph to predict an edge heatmap $P_{i, j} \in [0, 1]$ indicating the probability that edge $(i, j)$ belongs to the optimal tour:
- Node representations $h_i$ and edge distances $d_{ij}$ are fused via edge MLP layers:
  $$A_{i, j} = \sigma\left( W_{\text{edge}} [h_i, h_j, d_{ij}] + b_{\text{edge}} \right)$$
- The resulting continuous probability matrix serves as edge priors for highly efficient guided beam search or dynamic programming (e.g., restricted dynamic programming or branch-and-cut).

## 5. Reinforcement Learning for Combinatorial Solvers

Supervised training of neural solvers requires expensive ground-truth optimal solutions generated by exact solvers. Reinforcement Learning circumvents this bottleneck by treating tour length as a negative reward:
- **REINFORCE with Rollout Baseline (Kool et al.):** Policy network parameterized by $\theta$ generates tours with probability $P_\theta(\pi \mid X)$.
- Policy gradient update:
  $$\nabla_\theta \mathcal{J}(\theta) = \mathbb{E}_{X \sim \mathcal{D}, \pi \sim P_\theta} \left[ (\text{Cost}(\pi) - b(X)) \nabla_\theta \log P_\theta(\pi \mid X) \right]$$
- The baseline $b(X)$ is computed via deterministic greedy rollout of the best-performing historical checkpoint, drastically reducing gradient variance without introducing bias.

## 6. Continuous Relaxation of Constraint Satisfaction (Max-Cut, Ising Models)

Discrete constraint satisfaction problems can be mapped to continuous energy Hamiltonians. In the Max-Cut problem on an undirected graph with adjacency matrix $W$:
- Assign binary spins $\sigma_i \in \{-1, +1\}$ to partition nodes into two disjoint sets. The cut value is:
  $$\text{Cut}(\sigma) = \frac{1}{4} \sum_{i, j} W_{ij} (1 - \sigma_i \sigma_j)$$
- **Continuous Relaxation:** Parameterize spins through unconstrained continuous logits $z_i \in \mathbb{R}$ via differentiable hyperbolic tangent $\sigma_i = \tanh(z_i) \in (-1, 1)$.
- Gradient ascent on $\text{Cut}(\tanh(z))$ rapidly drives logits toward polarized binary values $\pm 1$, providing continuous optimization for discrete combinatorial constraints.

## 7. Hybrid Neural-Algorithmic Solvers

Modern production architectures blend neural inference with classical discrete algorithms:
- **Neural Heuristic Initialization:** Neural networks generate high-quality initial tours $\pi_0$ within milliseconds ($< 1\%$ optimality gap).
- **GPU-Accelerated Local Search:** Fast parallel 2-opt and Lin-Kernighan-Helsgaun (LKH) kernels iteratively refine $\pi_0$ by evaluating swap gains $\Delta = \|x_a - x_c\| + \|x_b - x_d\| - (\|x_a - x_b\| + \|x_c - x_d\|)$.
