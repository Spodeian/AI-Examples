# Recommenders: DLRM, DCN-v2, SASRec, and TIGER Semantic IDs

## 1. Industrial Recommender Systems: Scaling to Billions of Items

Modern recommendation platforms operate in a multi-stage funnel: Candidate Generation (retrieving hundreds of candidates from billions of catalog items) followed by Fine-Grained Ranking (evaluating candidates with complex cross-features under sub-10ms latency). The core computational workload centers on:
- **Massive Embedding Tables:** Sparse categorical features (user IDs, item IDs, search queries) spanning terabytes of memory.
- **High-Order Non-Linear Feature Crosses:** Intersecting user demographics with item categories and dynamic real-time contextual signals.
- **Sequential Behavioral Modeling:** Tracking evolving user preferences over historical interaction trajectories.

## 2. DLRM: Explicit Pairwise Dot-Product Feature Interactions

Meta's Deep Learning Recommendation Model (DLRM) splits tabular inputs into continuous dense signals and sparse categorical embeddings:
- Continuous features pass through a bottom MLP to yield dense representation $v_0 \in \mathbb{R}^D$.
- Sparse categorical features are mapped via embedding tables to vectors $v_1, \dots, v_S \in \mathbb{R}^D$.
- **Explicit Pairwise Interactions:** Rather than relying solely on black-box MLPs to learn feature correlations, DLRM computes exact dot products between all pairs:
  $$V = [v_0, v_1, \dots, v_S]^T \in \mathbb{R}^{(1 + S) \times D}$$
  $$M_{\text{interaction}} = V V^T \in \mathbb{R}^{(1 + S) \times (1 + S)}$$
- The unique off-diagonal interactions (strictly lower triangular indices $(i, j)$ with $i > j$, yielding $\frac{(1+S)S}{2}$ scalar features) are concatenated with the dense vector $v_0$ and fed into a top MLP for final click/conversion probability prediction.

## 3. Deep and Cross Network (DCN-v2): Explicit Bounded-Degree Crosses

Standard feed-forward layers learn feature crosses implicitly, requiring prohibitive parameter depth. DCN-v2 models explicit feature interactions of degree $d$ at layer $d$ with linear computational complexity:

$$x_{l+1} = x_0 \odot \left( x_l W_l + b_l \right) + x_l$$

where $x_0 \in \mathbb{R}^D$ is the initial concatenated embedding, $x_l \in \mathbb{R}^D$ is the activation at layer $l$, $W_l \in \mathbb{R}^{D \times D}$ is the cross weight matrix, and $\odot$ denotes elementwise product. By conditioning each cross directly on the original input $x_0$, DCN-v2 captures all polynomial combinations $\prod_{i} x_{0, i}^{\alpha_i}$ efficiently.

## 4. SASRec: Causally-Masked Self-Attentive Sequential Recommendations

Users exhibit dynamic temporal shifts in intent (e.g., browsing cameras, then lenses, then tripods). SASRec (Self-Attentive Sequential Recommendation) formulates user history as an ordered sequence $s = (i_1, i_2, \dots, i_t)$:
- Interaction sequence tokens are augmented with learnable positional embeddings: $E = [e_{i_1} + p_1, \dots, e_{i_t} + p_t]$.
- A Transformer backbone with lower-triangular causal masking prevents information leakage from future interactions:
  $$\text{Scores}_{j, k} = \begin{cases} \frac{q_j k_k^T}{\sqrt{D}} & \text{if } k \le j \\ -\infty & \text{if } k > j \end{cases}$$
- The output representation $h_t$ at step $t$ scores candidate items $j$ via inner product $\langle h_t, e_j \rangle$.

## 5. TIGER and Generative Recommendation: Replacing Atomic IDs with Semantic Codes

Traditional recommenders assign arbitrary atomic integer IDs ($1, 2, \dots, N$) to items. Atomic IDs suffer from three fundamental limitations:
1. **Cold Start & Unseen Items:** Zero embedding transfer to newly introduced catalog items.
2. **Unbounded Memory Scaling:** Embedding tables scale linearly $\mathcal{O}(N \cdot D)$ with catalog size.
3. **No Semantic Structure:** Similar products (e.g., two identical shirts of different colors) have completely orthogonal embeddings.

TIGER (Transformer Index for Generative Recommendation) discards atomic IDs, replacing them with hierarchical Semantic IDs generated by Residual Quantized VAE (RQ-VAE). Each item is represented as a compact tuple of discrete tokens: $(c_1, c_2, c_3) \in \{1, \dots, V\}^3$. Recommending items becomes an autoregressive sequence-to-sequence generation problem decoded via beam search.

## 6. Residual Quantized VAE (RQ-VAE)

To create semantic IDs, item text descriptions or image embeddings $x \in \mathbb{R}^D$ are quantized hierarchically through $K$ codebooks $\mathcal{C}_1, \dots, \mathcal{C}_K$:
- At step $1$, residual $r_0 = x$. Centroid $c_1 = \arg\min_v \| r_0 - \mathcal{C}_{1, v} \|^2$.
- Step $k$: $r_k = r_{k-1} - \mathcal{C}_{k, c_k}$. Centroid $c_{k+1} = \arg\min_v \| r_k - \mathcal{C}_{k+1, v} \|^2$.
- The coarse-to-fine sequence of indices $(c_1, \dots, c_K)$ forms the item's semantic ID. Items sharing code prefix $(c_1, c_2)$ naturally belong to the same product category and brand.

## 7. Optimization Objectives: InfoNCE and Binary Cross-Entropy

- **Classification / CTR Prediction:** Binary cross-entropy with focal loss or negative downsampling:
  $$\mathcal{L}_{\text{BCE}} = -y \log \hat{y} - (1 - y) \log(1 - \hat{y})$$
- **Contrastive Item Retrieval:** InfoNCE over in-batch negatives:
  $$\mathcal{L}_{\text{InfoNCE}} = -\log \frac{\exp(\langle q, d^+ \rangle / \tau)}{\exp(\langle q, d^+ \rangle / \tau) + \sum_{j} \exp(\langle q, d_j^- \rangle / \tau)}$$

## 8. Cross-Track Verification and Parity

All recommendation components are validated across the 7-track curriculum against seed-42 golden safetensors:
- **PyTorch 2.x:** Reference implementations of DLRM feature interactions, DCN-v2 cross layer, SASRec causal attention, and RQ-VAE quantization step.
- **JAX:** Functional implementation using `jnp.einsum`, `jnp.tril_indices`, and vectorized nearest-neighbor codebook quantization, verified to $< 10^{-5}$ error.
- **Candle:** Native Rust implementation with batched matrix multiplications, lower-triangular pair concatenation, and causal attention masking, passing `cargo test -p ai-candle --test 07_domain_tasks test_11`.
- **WGSL Kernel:** Fused DCN-v2 cross compute shader evaluating linear projection, bias addition, and elementwise multiplication in a single GPU pass.
